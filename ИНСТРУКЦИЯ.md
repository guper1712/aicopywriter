# Как скачать фото с U.S. Polo Assn (для новичка)

Программа берёт твой Excel-файл (столбцы «Артикул» и «Цвет»), находит каждый
товар на сайте https://tr.uspoloassn.com/ и скачивает **все фото всех цветов**
в папки.

Результат:
- папка для каждого цвета: `photos/<артикул>_<цвет>/`
- фото внутри: `<артикул>_<цвет>_1.jpg`, `<артикул>_<цвет>_2.jpg`, …
- отчёт `photos/_report.csv` — что нашлось, что нет.

> Артикулы, которых нет на сайте (распроданы/сняты), просто пропускаются.

---

## Windows — самый простой способ

1. **Установи Python** (один раз): https://www.python.org/downloads/
   При установке **обязательно** поставь галочку **«Add Python to PATH»**.
2. Создай папку, например `uspolo`, и положи туда **3 файла**:
   - `uspolo_parser.py`
   - `run_windows.bat`
   - свой Excel — **переименуй его в** `articles.xlsx`
3. **Дважды кликни** по `run_windows.bat`.
4. Жди. Фото появятся в папке `photos`.

---

## Mac / вручную

```bash
pip install requests openpyxl

# пробный прогон на 2 артикулах (ничего не качает, только показывает):
python3 uspolo_parser.py --excel articles.xlsx --out photos --limit 2 --dry-run

# полный запуск:
python3 uspolo_parser.py --excel articles.xlsx --out photos
```

Полезные ключи:
- `--limit 10` — обработать только первые 10 артикулов (для проверки);
- `--dry-run` — показать, что бы скачалось, без сохранения файлов.

Программу можно запускать повторно — уже скачанные фото она пропускает.
